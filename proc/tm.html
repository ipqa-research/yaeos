public function tm(model, z, w, P, T, d, dtpd)

tm

Evaluate Michelsen’s modified reduced tangent-plane distance.

Description

Alternative formulation of the reduced tangent plane function, where the test phase is defined in moles, which enables for unconstrained minimization.

Examples

Calculation of tm

 tpd_value = tm(model, z, w, P, T)

Using precalculated feed data

It is possible to calculate externally the feed d_i vector and use it for later calculations.

call model%lnphi_pt(z, T=T, P=P, V=Vz, root_type="stable", lnPhi=lnphi_z)
d = log(z) + lnphi_z
tpd_value = tm(model, z, w, P, T, d=d)

References

  1. Thermodynamic Models: Fundamental and Computational Aspects, Michael L. Michelsen, Jørgen M. Mollerup. Tie-Line Publications, Denmark (2004) doi
