public function pt_envelope_3ph(model, z, x0, y0, w0, beta0, P0, T0, ns0, dS0, points) result(envelope)

pt_envelope_3ph

Description

Trace a three-phase pressure-temperature envelope at fixed feed z.

The initial phase compositions, pressure, temperature, and phase fraction define the starting state. Subsequent points are generated by continuation and corrected by solving the three-phase equilibrium equations. The returned arrays contain only points that converged.
