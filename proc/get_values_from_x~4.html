public subroutine get_values_from_X(z, Xvars, x, y, w, P, T, beta)

get_values_from_X

Description

Decode logarithmic equilibrium variables into phase states. The unknown vector stores log(Kx), log(Ky), log(P), log(T), and beta; phase compositions are reconstructed with the material balance.
