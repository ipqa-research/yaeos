public function flash_second_order(model, z, T, P_spec, k0, light_root, iters, tol, max_iters) result(flash)

flash_second_order

Description

Find a two-phase split at fixed temperature and pressure by minimizing the reduced Gibbs energy with a second-order method.

Arguments

  • model: thermodynamic model (ArModel or GeModel).
  • z: global mole fractions.
  • T: temperature [K].
  • P_spec: pressure [bar].
  • k0: optional initial K-factors. If omitted, Wilson factors are used for ArModel and a stability analysis is used for GeModel.
  • light_root: root used for the light phase with ArModel ("stable" by default, "liquid" for a liquid-liquid split).
  • iters: number of iterations used.
  • tol: gradient-norm tolerance (default 1e-8).
  • max_iters: maximum number of iterations (default 200).
