public subroutine newton_1d(f, x, tol, max_iters, failed)

newton_1d

Description

Find a root of a scalar function by damped Newton iteration. Each step is halved until its magnitude is at most half the current iterate’s magnitude. This is a step-size safeguard, not a residual line search.
