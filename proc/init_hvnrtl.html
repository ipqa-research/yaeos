Huron-Vidal NRTL mixing rule

This is the Huron-Vidal mixing rule that includes the NRTL model modified by Huron and Vidal.

Description

This is the Huron-Vidal mixing rule that includes the NRTL model modified by Huron and Vidal. It is a mixing rule that allows to use the NRTL model as an excess Gibbs energy model and can be simplified to the classic quadratic mixing rules when the parameters are set to:

Examples

mixrule = HV_NRTL(b, del1, alpha, gji0, gjiT, use_kij, kij)
