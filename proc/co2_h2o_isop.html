co2_h2o_isop

Construct the CO2-water-isopropanol three-component fixture.

Description

Returns a Soave-Redlich-Kwong model with binary interaction parameters, a reference composition, and a second composition for comparison.

Examples

fluid = co2_h2o_isop()

Arguments

None

Return Value type(FixtureFluid)
