public subroutine min_tpd(model, z, P, T, mintpd, w, all_minima)

min_tpd

Find the minimum of the reduced tangent-plane distance.

Description

Minimizes Michelsen’s modified tangent-plane distance with respect to the trial-phase mole numbers. A negative minimum indicates that the feed is unstable. The routine can optionally return all the minima found from different starting points.
