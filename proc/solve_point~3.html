public subroutine solve_point(eos, n, P, T, V, Pcalc, ZETA, ZETMIN, ZETMAX, AT, iter)

solve_point

Correct one pressure root in reduced-covolume coordinates.

Description

Updates with a bracketed Newton step, maintaining ZETMIN and ZETMAX as the current root bounds.
