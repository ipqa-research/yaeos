create_generalized_isoz_line

Start a generalized multiphase isopleth from an existing phase state.

Description

Packs initial K-factors, phase fractions, pressure, and temperature into the continuation state; optional stability trial compositions seed phase discovery. It then follows the specified solution branch and returns the converged multiphase states.

Examples

Use a converged multiphase state and provide its phase kinds, compositions, fractions, and continuation specification.
