public function optval_character(val, default)

optval_character

Return the optional character value or its fallback.

Description

Selects val when present and otherwise returns default; the result is allocated to the selected string length.

Arguments

Type IntentOptional Attributes Name
character(len=*), intent(in), optional :: val

Optional character value.
character(len=*), intent(in) :: default

Value returned when val is absent.

Return Value character(len=:), allocatable
