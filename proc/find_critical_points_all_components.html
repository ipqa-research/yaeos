public subroutine find_critical_points_all_components(model, nc, Vc, Tc, Pc, converged)

find_critical_points_all_components

Estimate pure-component critical constants for every model component.

Description

For each component, first obtains a starting estimate from pure-fluid saturation calculations, then solves the criticality equations and with a two-variable Newton iteration. A failed solve is reported in converged; the corresponding output values contain the final iterate and must not be treated as validated critical constants.

Examples

call find_critical_points_all_components(model, nc, Vc, Tc, Pc, ok)
