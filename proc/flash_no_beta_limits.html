flash_no_beta_limits

Description

Flash algorithm using successive substitutions that, unlike flash, does not rescale the K-factors with betato01 to force , so negative-flash solutions can be reached.

Available specifications:

  • TP (with T and P_spec variables)
  • TV (with T and V_spec variables)

Failure handling is the same as in flash.
