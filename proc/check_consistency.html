public subroutine check_consistency(self)

check_consistency

Validate group-contribution parameter-array dimensions.

Description

Checks that subgroup identifiers, subgroup-to-main-group mapping, group-size/area data, and interaction-parameter matrices have compatible dimensions. Stops with an error message at the first inconsistent array shape.

Examples

call parameters%check_consistency()
