public function continuation(f, X0, ns0, S0, dS0, max_points, solver_tol, update_specification, postprocess, solver, stop) result(XS)

continuation

Trace a one-dimensional solution manifold of a nonlinear system.

Description

At each point the tangent is obtained from

The tangent predicts the next point; solver (or the default Newton corrector) then solves the residual equations there. The default specification update selects the component of the tangent with the largest magnitude, rescales the tangent to it and converts the step to that variable (no step-size limit is applied). Tracing stops when the corrector reaches its iteration limit (500), the residual is NaN, dS becomes zero, or stop returns true. The returned array has max_points rows; rows not reached before termination remain zero.

Examples

curve = continuation(fun, X0, ns0, S0, dS0, &
   max_points=100, solver_tol=1.0e-8_pr)
