yaeos Python API

The yaeos Python API is in an early stage of development, so the API will change with time. The supported operating system is Linux, and the supported Python versions are 3.10, 3.11, 3.12 and 3.13.

Important advice

Since yaeos is written in Fortran, Python users can have some little issues understanding and finding things in the documentation. Please, we recommend looking at the “Getting Started - Using This Documentation” section of the Tutorial down below, there you will understand how to use this documentation.

Start with a physical question

  • What pressure or volume does this fluid have? Choose an equation of state and follow the EoS tutorials.

  • How nonideal is a liquid mixture? Start with excess Gibbs models for activity coefficients and liquid-liquid separation.

  • Will the mixture split into phases? Read phase equilibrium before using flash or saturation methods.

New users should follow the Tutorial in order. The API pages below give exact signatures; common property and equilibrium methods are inherited from Core Module, not repeated on every model page.

Input conventions to keep nearby

The property methods use kelvin, bar, litres, and moles. Energies reported in bar L convert to joules by multiplying by 100. Check each signature: moles is an amount vector, whereas z in equilibrium calculations is an overall mole-fraction vector summing to one. A mole-fraction vector used as moles chooses a one-mole basis; the corresponding volume is then the volume of that one mole.

Keep the same component order in every parameter array, composition vector, and row/column of an interaction matrix. Outputs use that same order. Mass fractions must be converted to mole fractions before use. Residual and excess energies are contributions relative to a reference, not complete enthalpies or Gibbs energies; see Core Module before making an energy balance.
