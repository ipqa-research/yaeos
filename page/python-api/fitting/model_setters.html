Model Setters Fitting module

A model setter converts the optimizer’s trial parameter vector into a model that the Core Fitting module fitter can score. The convention used throughout the package is setter(parameters, *args) -> ArModel: the parameters come first, and the extra arguments are the ones passed to the fitter as model_setter_args.

The supplied setters

fit_kij_lij(x, model, fit_kij, fit_lij)

Updates the model’s mixing rule with binary interaction parameters. When both are fitted, the vector is [kij, lij]; when only one is fitted, the vector has a single element. The matrices are built symmetric, so this setter cannot represent directional 12/21 differences.

fit_mhv_nrtl(x, args) and fit_hv_nrtl(x, args)

Build an NRTL excess-Gibbs model and couple it to the cubic EoS through the MHV or HV mixing rule. Their extra arguments arrive as a single tuple, args = (model, q) for MHV and args = (model,) for HV, so pass them to the fitter wrapped once more, for example model_setter_args=((model, q),). The parameter vector is [a12, a21, b12, b21, alpha], matching the NRTL convention tau_ij = a_ij + b_ij / T with G_ij = exp(-c_ij tau_ij): a and alpha are dimensionless, b is in K, and the 12 and 21 entries are independent.

Practical notes

  • The vector order is part of the interface. A vector of the right length but the wrong order will silently fit the wrong parameters.

  • Setters mutate the model and return it. Keep the parameter vector yourself if you need to know which values produced a given result.

  • Writing your own setter is normal and often better than using the supplied ones: it lets you fit parameters the helpers do not cover, such as asymmetric kij values or several parameters at once. Follow the same calling convention and return the updated model.

See Core Fitting module for how the setter is called and the fitting tutorial for a complete worked example, including a custom setter.

Model Setters.

Compilation of functions that set a model’s parameters to the values given in the input arguments.

fit_kij_lij(x, model, fit_kij, fit_lij)[source]

Set the kij and/or lij parameter of the model.

Intended to be used as model_setter in BinaryFitter with model_setter_args=(model, fit_kij, fit_lij).

Parameters:

  • x (array_like) – Optimization parameters: [kij, lij] if both are fitted, otherwise [kij] or [lij].

  • model (CubicEoS) – Binary cubic EoS whose mixing rule has kij and lij attributes (e.g. QMR).

  • fit_kij (bool) – Whether to fit the kij parameter.

  • fit_lij (bool) – Whether to fit the lij parameter.

Returns:

The same model object with its mixing rule updated.

Return type:

CubicEoS

fit_mhv_nrtl(x, args)[source]

Set an MHV mixing rule with NRTL GE in a binary cubic EoS.

Parameters:

  • x (array_like) – Optimization parameters [a12, a21, b12, b21, alpha] of the NRTL model.

  • args (tuple) – (model, q): the cubic EoS and the MHV q parameter. Note that BinaryFitter calls the setter as model_setter(x, *model_setter_args), so this tuple must be wrapped: model_setter_args=((model, q),).

Returns:

The same model object with its mixing rule updated.

Return type:

CubicEoS

fit_hv_nrtl(x, args)[source]

Set an HV mixing rule with NRTL GE in a binary cubic EoS.

Parameters:

  • x (array_like) – Optimization parameters [a12, a21, b12, b21, alpha] of the NRTL model.

  • args (tuple) – (model,): the cubic EoS. Note that BinaryFitter calls the setter as model_setter(x, *model_setter_args), so this tuple must be wrapped: model_setter_args=((model,),).

Returns:

The same model object with its mixing rule updated.

Return type:

CubicEoS
