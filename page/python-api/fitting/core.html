Core Fitting module

BinaryFitter scores a model against experimental data and drives an optimizer over the interaction parameters. It needs three things from you: a model setter that builds a model from a parameter vector, the data to fit, and (optionally) the error definitions to use.

Data format

The data is a pandas DataFrame. The documented columns are:

kind

Which measurement was made. The documented values are bubbleT, bubbleP, dewT, dewP, PT, liquid-liquid, and critical; the shorter aliases bubble and dew are also accepted. Use critical rather than the CP alias: the critical line is only computed when at least one row has kind == "critical", so a data set that marks critical points only as CP fails.

T

Temperature in K.

P

Pressure in bar.

x1

Mole fraction of component 1 (the light component) in the heavy phase.

y1

Mole fraction of component 1 (the light component) in the light phase.

weight (optional)

Relative weight of the point; points without a weight count as 1.

What each kind does with the data:

  • bubbleP compares the experimental pressure with the bubble saturation pressure at T for the liquid of composition x1.

  • bubbleT compares the experimental temperature with the bubble saturation temperature at P for the liquid of composition x1.

  • dewP and dewT do the same for the dew point, using the vapor composition y1.

  • PT and liquid-liquid compare the two-phase equilibrium computed at P and T with the experimental compositions.

  • critical compares the experimental point with the nearest point on the model’s calculated critical line.

x1 and y1 are mole fractions of the same component in the two phases, not fractions of two different components. Columns that a given kind does not use may be left as NaN. An unrecognized kind raises ValueError.

How the fit runs

fit(x0, bounds=None, method="Nelder-Mead", optimizer_options=None) minimizes the objective with scipy.optimize.minimize. x0 is the initial parameter guess, bounds may be None or a sequence of (min, max) pairs, one per fitted parameter, and optimizer_options is passed to minimize as options. The optimizer result is stored in the solution property, and the model property rebuilds the fitted model as model_setter(solution.x, *model_setter_args).

Errors and diagnostics

The default pressure error is the squared difference between the experimental and model pressures divided by the experimental pressure; the temperature error does the same with temperatures. Points at low values therefore weigh more heavily than the raw difference suggests. The default composition error is the sum of the absolute log ratios of the two light-component mole fractions, which punishes near-zero compositions heavily. Supplying your own pressure_error, temperature_error, or composition_error callables changes what the objective value means, so keep the definitions consistent when comparing fits.

Read the residuals stored in evaluations["residuals"] and the per-point contributions in evaluations["contributions"]: an overall objective value can hide a few badly predicted points. Check the fitted model against data that were not used in the fit, and confirm that the phases found are the expected ones before trusting the parameters.

See Model Setters Fitting module for the parameter-vector conventions and Solvers Fitting module for the equilibrium calculations used by the PT and liquid-liquid data kinds.

BinaryFitter class.

This class is used to fit binary interaction parameters to experimental data. The objective function is defined as the sum of the squared errors between the experimental data and the model predictions.

Parameters:

  • model_setter (Callable) – A function that returns a model object. It is called as model_setter(x, *model_setter_args), so it should take the optimization parameters as the first argument and the elements of model_setter_args as the following arguments.

  • model_setter_args (tuple) – A tuple with the arguments to pass to the model_setter function.

  • data (pandas.DataFrame) –

    A DataFrame with the experimental data. The DataFrame should have the following columns:

    • kind: str, the kind of data point. Accepted values are “bubble” (or “bubbleP”), “bubbleT”, “dew” (or “dewP”), “dewT”, “PT”, “liquid-liquid” and “critical”.

    • x1: float, the mole fraction of component 1 (lightest component) in heavy phase.

    • y1: float, the mole fraction of component 1 (lightest component) in light phase.

    • T: float, the temperature in K

    • P: float, the pressure in bar

    • weight: float, optional, the weight of the data point (default is 1)

  • verbose (bool, optional) – If True, print the objective function value and the optimization parameters at each evaluation.

  • pressure_error (Callable, optional) – A function f(Pexp, Pmodel) that calculates the pressure error between the experimental and model values. The function should take the experimental and model values as arguments and return the error. If None, the default function is used.

  • temperature_error (Callable, optional) – A function f(Texp, Tmodel) that calculates the temperature error between the experimental and model values. The function should take the experimental and model values as arguments and return the error. If None, the default function is used.

  • composition_error (Callable, optional) – A function f(zexp, zmodel) that calculates the composition error between the experimental and model values. The function should take the experimental and model for mixture composition as arguments and return the error. If None, the default function is used.

Fit the model to the data.

Fit the model to the data using the objective function defined in the objective_function method. The optimization is performed using the scipy.optimize.minimize function. The optimization result is stored in the .solution property, and the fitted model can be obtained with the .model property.

Parameters:

  • x0 (array-like) – Initial guess for the fitting parameters.

  • bounds (array-like, optional) – Bounds for the fitting parameters, by default None.

  • method (str, optional) – The optimization method to use. Default is ‘Nelder-Mead’.

  • optimizer_options (dict, optional) – Options passed to scipy.optimize.minimize as options, by default None.

Return type:

None
