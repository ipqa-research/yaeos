Cubic EoS

Use a concrete class such as PengRobinson76 or SoaveRedlichKwong; CubicEoS supplies their shared interface. Parameter arrays must have matching lengths and component order. Critical temperatures are in K, critical pressures in bar, and acentric factors are dimensionless. RKPR additionally needs critical compressibility factors.

For example, this builds a methane/ethane model (methane first, ethane second) and round-trips a homogeneous state: the volume is solved at a given pressure and temperature, and the pressure is then recomputed from that volume. The two pressures should agree to within the solver’s tolerance.

import numpy as np
from yaeos import PengRobinson76

model = PengRobinson76([190.56, 305.32], [45.99, 48.72], [0.0115, 0.0985])
n = np.array([0.8, 0.2])  # mol; methane first, ethane second
V = model.volume(n, 1.0, 300.0)  # L at 1 bar and 300 K
P = model.pressure(n, V, 300.0)  # bar; should come back near 1.0
assert np.isfinite(V) and V > 0
assert np.isclose(P, 1.0, rtol=1e-3)

The default mixing rule for the ordinary PR/SRK constructors is quadratic with zero interaction parameters. Zero is a starting assumption, not a fitted result. PSRK also requires molecular groups (its Mathias-Copeman alpha-function parameters are optional); it is not created from critical constants alone.

Continue with Mixing Rules and Core Module for properties, root selection, and phase-split calculations.

from yaeos import PSRK

# methanol/n-hexane mixture
tc = [512.5, 507.6]   # Critical temperatures [K]
pc = [80.84, 30.25]     # Critical pressures [bar]
w = [0.565831, 0.301261]    # Acentric factors

# Methanol: 1 CH3OH subgroup
# n-hexane: 2 CH3, 4 CH2 subgroups
molecules = [{15:1}, {1:2, 2:4}]

# Mathias-copeman constants
c1 = [1.31458917, 0.93830213]
c2 = [0.0, 0.0]
c3 = [0.0, 0.0]

psrk = PSRK(tc, pc, w, molecules=molecules, c1=c1, c2=c2, c3=c3)

# The dictionary of molecules can be created using the `ugropy` library

import ugropy as ug

molecules = ["methanol", "ethanol"]

groups = [ug.get_groups(ug.psrk, molecule) for molecule in molecules]
molecules = [
    ug.writers.to_thermo(grp.subgroups, ug.psrk) for grp in groups
]

print(molecules)
# [{15: 1}, {1: 1, 2: 1, 14: 1}]
