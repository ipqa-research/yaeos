Alpha Functions

The alpha function sets the temperature dependence of a cubic EoS attractive parameter. Each cubic model has a default alpha function; an alternative can be set on an existing model with model.set_alpha(...).

AlphaSoave and AlphaRKPR take one dimensionless k value per component, and AlphaMathiasCopeman takes three coefficient vectors c1, c2 and c3. All vectors follow the same component order as the critical constants. Changing the alpha function changes pure-component vapor pressures, so check them before fitting binary interactions.

Follow the alpha-function notebook for examples.

Alpha Functions for CubicEoS.

This module contains the setter functions for the different alpha functions existing in yaeos.

Example

from yaeos import AlphaSoave, SoaveRedlichKwong

k = [0.5, 0.6]

alphasoave = AlphaSoave(k)  # AlphaSoave with custom parameters

tc = [305.32, 469.7]        # critical temperature [K]
pc = [48.72, 33.7]          # critical pressure [bar]
w = [0.0995, 0.152]         # acentric factor

model = SoaveRedlichKwong(tc, pc, w)
model.set_alpha(alphasoave)
