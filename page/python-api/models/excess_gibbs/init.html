Excess Gibbs Models

These models describe how a liquid mixture differs from ideal mixing. Their activity coefficients correct each component’s liquid-phase chemical potential: ln_gamma returns the natural logarithm, so use numpy.exp(model.ln_gamma(n, T)) to obtain gamma. Gamma near one means a small activity correction at that composition, not necessarily a stable single liquid phase.

Use NRTL or UNIQUAC with suitable fitted interaction parameters. Use the UNIFAC variants when representing molecules by functional groups, checking the variant’s group definitions and available interactions first. The variants are distinct parameterizations, not interchangeable names.

Inputs to property methods are component moles and temperature in K; equilibrium methods take overall mole fractions. Keep the constructor’s component order throughout. flash_t describes a liquid-liquid split, not boiling: these models alone do not provide a vapor equation of state or pure-component vapor pressures. See Core Module for inherited methods and Excess Gibbs models for examples.

Gibbs Excess Models module.

Yaeos Gibbs excess module. This module provides the following excess Gibbs energy models:

  • NRTL: non-random two-liquid model

  • UNIFACVLE: original UNIFAC VLE model

  • UNIFACPSRK: PSRK-UNIFAC model

  • UNIFACDortmund: UNIFAC Dortmund model

  • UNIQUAC: UNIversal QUAsiChemical model
