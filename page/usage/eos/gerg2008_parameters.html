GERG2008 parameters

This page lists every parameter that yaeos uses to evaluate the GERG2008 residual Helmholtz energy: the pure-fluid constants, the pure-fluid residual coefficients, the binary reducing parameters and the binary departure functions. Use it to check what the model assumes about a component or a pair, or to compare yaeos with another implementation.

The tables were generated from the values that the compiled module yaeos__models_ar_multifluid_parameters_gerg2008 (src/models/residual_helmholtz/multifluid/parameters_gerg2008.f90) holds after it loads its tables, and were checked against the literals in that file. They describe the code, so if the source changes, the source wins.

How to read the tables:

  • Indices. and are the internal GERG2008 table indices, equal to the values of the G2008Components fields (G2008Components%methane is 1, G2008Components%argon is 21). They are not the component order of a model built with gerg_2008: the constructor picks the rows and pairs that belong to the identifiers you pass.
  • Pair order. Binary parameters are listed once per pair, with . The reverse order is derived, as explained in Binary reducing parameters.
  • Residual part only. yaeos implements only the residual contribution. The module also stores the ideal-gas coefficients (n0i, th0i) of the original formulation, but no yaeos routine uses them, so they are not listed here.
