What a cubic model does

A cubic equation of state is a compact way to estimate fluid pressure, density and phase behavior from a small set of pure-component data. PR and SRK are useful starting points for hydrocarbon mixtures; choosing one does not guarantee accurate liquid densities or strongly polar-mixture behavior. Compare with measurements in your temperature, pressure and composition range.

Think of the model as a balance between molecules taking up space and molecules attracting one another. For a mixture, the mixing rule combines pure-component parameters. The alpha function first adjusts each pure component’s attraction with temperature: these are different jobs. PR, SRK and RKPR default to quadratic mixing with zero binary corrections unless supplied; PSRK uses an excess-Gibbs mixing rule instead.

Required data and a first calculation

For PR and SRK, supply arrays tc (K), pc (bar), and w (dimensionless acentric factor). The acentric factor summarizes pure-fluid vapor-pressure behavior; it is not a composition. Every array must use the same component order. Optional kij and lij are dimensionless square matrices in that order, normally symmetric with zero diagonals. They require a suitable parameter source or fitting; zero is a baseline, not a universal fit.

This complete program uses methane then n-butane. It evaluates a specified homogeneous state without asking an equilibrium solver to find a state. The API takes mole amounts n (mol) and total V (L), not molar volume. Here the one-mole basis makes their numerical values coincide.

program cubic_pressure
   use yaeos, only: pr, R, CubicEoS, PengRobinson76
   implicit none
   type(CubicEoS) :: model
   real(pr) :: tc(2)
   real(pr) :: pc(2)
   real(pr) :: w(2)
   real(pr) :: n(2)
   real(pr) :: T
   real(pr) :: V
   real(pr) :: P
   real(pr) :: Pideal

   tc = [190.564_pr, 425.12_pr]
   pc = [45.99_pr, 37.96_pr]
   w = [0.0115478_pr, 0.200164_pr]
   model = PengRobinson76(tc, pc, w)
   n = [0.3_pr, 0.7_pr]
   T = 300.0_pr
   V = 10.0_pr
   call model%pressure(n, V, T, P)
   Pideal = sum(n)*R*T/V
   print *, "Pressure [bar]: ", P
   print *, "Ideal-gas pressure [bar]: ", Pideal
   print *, "Compressibility Z [-]: ", P/Pideal
end program cubic_pressure

Link this program with yaeos and its dependencies in your configured Fortran/fpm environment. pr is the library’s real kind; _pr literals avoid rounding inputs to default real precision. The dimensionless compressibility factor should approach one at small density. Scaling both n and V by the same positive factor should leave pressure unchanged.

RKPR

RKPR

The RKPR EoS [2] extends the classical formulation of Cubic Equations of State by freeing the parameter and setting [1]. This extra degree provides extra ways of implementing the equation in comparison of other Cubic EoS (like PR and SRK) which are limited to definition of their critical constants.

Besides that extra parameter, the RKPR includes another function:

Its constructor is RKPR(tc, pc, w, zc, kij, lij, delta_1, k); arguments after zc are optional. Here zc is the experimental critical compressibility , with the critical molar volume. RKPR needs this additional pure-component information. Optional delta_1 and k arrays each have one entry per component.

The implementation uses an effective critical compressibility 1.168*zc in its default shape correlation and numerically readjusts unspecified k values to match the acentric-factor definition at . This numerical fit is not an unconditional convergence guarantee. The implemented correlations are documented with RKPR; do not substitute experimental zc directly into an unrelated published correlation. Check that correlated parameters are finite, particularly near the fractional-power correlation’s domain boundary.

Because the refit solves a saturation condition per component, building an RKPR model is noticeably more expensive than building PR or SRK, and it can be sensitive to the input zc values.

PSRK

PSRK

The PSRK EoS [3,4] (Predictive Soave-Redlich-Kwong) is a Soave-Redlich-Kwong cubic equation of state that uses the MHV mixrule and a PSRK-UNIFAC model. The alpha function is Soave by default, or AlphaMathiasCopeman when the optional c1, c2, and c3 parameters are provided.

PSRK additionally needs one group decomposition per component, using the PSRK-UNIFAC group definitions and available interaction parameters. It does not infer molecular structure from critical constants. Supply all three alpha coefficient arrays together if overriding its default. See the group-contribution guide.

Interpreting results and avoiding false confidence

  • Use positive temperatures and volumes, nonnegative amounts and a positive total amount. Volume must exceed the mixture covolume; approaching that boundary makes pressure diverge.
  • pressure evaluates a mathematical homogeneous state. It does not decide whether that state will separate into liquid and vapor.
  • At fixed pressure and temperature there can be several volume roots. Requesting a liquid or vapor root is a branch choice, not proof that this phase is globally stable. Negative pressures on stretched branches are not a predicted operating pressure for an equilibrium vessel.
  • A converged flash cannot repair unsuitable parameters. Conversely, a failed flash is not proof the EOS is invalid. Check units, root selection, initial guesses and material balances separately.
