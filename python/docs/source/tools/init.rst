Tools
=====

The ``yaeos.tools`` package holds small helpers for moving parameter data
between Python and Fortran representations. It does not compute properties
or perform phase-equilibrium calculations.

Use :doc:`writers` to format parameter arrays as Fortran source. For
thermodynamic work start with :doc:`/models/init` and the shared methods in
:doc:`/core` instead.
