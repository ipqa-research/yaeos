type, public :: PurePsat

PurePsat

Saturation line of a pure component. Contains the saturation temperatures, pressures, and phase volumes, together with linear interpolators for get_T and get_P.

Description

Each point array shares the same index along the saturation curve. The interpolation methods should be used within the stored pressure or temperature interval.

Examples

psat = pure_saturation_line(model, component=1, minP=0.1_pr, minT=100.0_pr)
tsat = psat%get_T(P=1.0_pr)
