type, public, extends(CubicMixRule) :: HV

HV

Huron-Vidal cubic mixing rule.

Description

Couples an excess-Gibbs model with a cubic EOS through the infinite-pressure-limit relation. Component covolumes (bi) and values (del1) are stored in the type; there is no custom constructor, so use the structure constructor.

Examples

The initialized variants exported here are MHV and HV_NRTL.
