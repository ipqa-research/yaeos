type, public, abstract, extends(GeModel) :: GeModelAdiff

GeModelAdiff

Base type for hyperdual excess-Gibbs models.

Description

Concrete extensions implement the hyperdual-valued Ge function. This adapter evaluates it with derivative seeds in composition and temperature, then provides the GeModel excess-Gibbs derivative API.

Examples

See the UNIFAC implementation for a model using hyperdual AD.
