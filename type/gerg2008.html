type, public, extends(ArModelAdiff) :: Gerg2008

Gerg2008

GERG2008 multifluid equation of state. Holds the pure-fluid and binary parameters of the selected components and an SRK model used to initialize the volume solver.

Description

Provides the standard residual Helmholtz properties through the inherited hyperdual adapter and specializes volume solving with an SRK initial estimate.

Examples

model = gerg_2008([G2008Components%methane, G2008Components%nitrogen])
call model%pressure(n, V, T, P)
