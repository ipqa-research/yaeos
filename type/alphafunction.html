type, public, abstract :: AlphaFunction

AlphaFunction

Abstract contract for temperature corrections to cubic attraction.

Description

Implementations return component-wise and its first two derivatives with respect to reduced temperature. CubicEoS converts those derivatives to absolute-temperature derivatives.

Examples

See AlphaSoave, AlphaRKPR, and AlphaMathiasCopeman.
