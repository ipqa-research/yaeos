type, public, extends(CubicMixRule) :: HV_NRTL

HV_NRTL

Huron-Vidal cubic mixing rule with an NRTL-HV excess-Gibbs model.

Description

This variant evaluates the Huron-Vidal relation using the modified NRTL expression. Under the limiting parameter choices below, its attractive mixing expression reduces to the quadratic form.

Examples

mixrule = HV_NRTL(b, del1, alpha, gji0, gjiT, use_kij, kij)
call model%set_mixrule(mixrule)
