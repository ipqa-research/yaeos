type, public, abstract :: BaseModel

BaseModel

Common parent type for models that operate on a component set.

Description

Provides component metadata used by property and phase-equilibrium routines. Concrete model families extend this type with their thermodynamic equations and model-specific parameters.

Examples

See the ArModel and GeModel interfaces for concrete extensions.
