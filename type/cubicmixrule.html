type, public, abstract :: CubicMixRule

CubicMixRule

Abstract contract for cubic-EOS mixture parameter calculations.

Description

Concrete mixing rules implement attractive, repulsive, and cubic denominator parameter mixing, including derivatives needed for residual properties and phase equilibrium.

Examples

See QMR, CMR, MHV, and HV_NRTL for implementations.
