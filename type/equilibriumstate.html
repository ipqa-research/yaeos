type, public :: EquilibriumState

EquilibriumState

Result of a two-phase flash or saturation-point calculation.

Description

Stores the state kind, phase compositions, volumes, conditions, phase fraction, and iteration count. x denotes the heavy phase and y the light phase; beta is the light-phase mole fraction.

Examples

print *, result%P, result%T, result%beta
