type, public :: GeneralizedIsoZLine

GeneralizedIsoZLine

Stored points and stability status for a multiphase isopleth.

Description

points contains converged equilibrium states in continuation order. Stability flags and the most stable trial composition record the last stability assessment.

Examples

Iterate over line%points and inspect each state’s pressure, temperature, and phase compositions.
