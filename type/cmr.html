type, public, extends(CubicMixRule) :: CMR

CMR

Cubic mixing rule with ternary component interactions.

Description

CMR depends on ternary interaction parameters; on a Cubic EoS the mixture is obtained by the combination of attractive and repulsive parameter tensors.

By default the attractive parameter matrix is calculated with: generating the tensor, but this procedure can be overridden in an extended type by rebinding the aijk type-bound procedure.

Examples

rule = CMR(k=kijk, l=l3)
call model%set_mixrule(rule)
