type, public, abstract, extends(GeModel) :: GeModelTapenade

GeModelTapenade

Base class for excess-Gibbs models with Tapenade-generated derivatives.

Description

A concrete extension supplies primal, tangent, adjoint, and mixed derivative routines. The type adapts them to the standard GeModel excess-Gibbs interface.

Examples

See the implementation template in tools/tapenade_diff/ge_models/.
