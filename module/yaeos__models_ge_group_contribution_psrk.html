setup_psrk

PSRK UNIFAC model

Description

Group-contribution model used by the PSRK equation of state. Use setup_psrk to build the model from the groups of each molecule. Uses the PSRK group parameter set with the UNIFAC combinatorial and residual contributions.

Examples

model = setup_psrk(molecules)
call model%ln_activity_coefficient(n, T, ln_gamma)
