Temperature dependence for group-contribution models

Description

Abstract PsiFunction type and the concrete temperature-dependent functions used by UNIFAC-like models. UNIFACPsi implements , while QuadraticPsi implements (Dortmund and PSRK). Both also return the first two temperature derivatives.

Examples

call psi_model%psi(systems_groups, T, psi, dpsi_dT, d2psi_dT2)
