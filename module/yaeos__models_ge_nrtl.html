excess_gibbs

NRTL activity-coefficient model

Description

Non-Random-Two-Liquid model for excess Gibbs energy. The constructor is NRTL and the model extends GeModel. It uses local compositions and temperature-dependent pair interactions to represent liquid non-ideality.

Examples

model = NRTL(A, B, alpha)
call model%ln_activity_coefficient(n, T, ln_gamma)

References

Renon, H., and J. M. Prausnitz (1968). Local compositions in thermodynamic excess functions for liquid mixtures. AIChE Journal, 14, 135-144.
