px_envelope_2ph

Pressure-composition phase envelopes

Continue a two-phase boundary at fixed temperature between limiting feeds.

Description

The continuation parameter interpolates the overall feed between two limiting compositions. The module returns pressure, phase compositions, phase volumes, and detected critical points in PXEnvel2.

Examples

line = px_envelope_2ph(model, z0, alpha0, z_injection, first_point)
