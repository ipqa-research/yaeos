setup_dortmund

Dortmund UNIFAC model

Description

Modified UNIFAC (Dortmund) group-contribution model. Use setup_dortmund to build the model from the groups of each molecule. The constructor loads the Dortmund parameter tables and installs the Dortmund temperature dependence on the shared UNIFAC implementation.

Examples

model = setup_dortmund(molecules)
call model%ln_activity_coefficient(n, T, ln_gamma)
