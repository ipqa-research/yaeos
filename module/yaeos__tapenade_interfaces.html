Tapenade runtime stack interfaces

Fortran interfaces to the push/pop routines used by Tapenade-generated adjoint code.

Description

These external procedures exchange scalar and array values with the Tapenade AD stack. They are implementation support for generated derivative routines and are not normally called directly by model users.

Examples

The interfaces are invoked from Tapenade-generated code during reverse mode evaluation.
