Implemented cubic equations of state

Description

Constructors for the cubic equations implemented in yaeos:

  • PengRobinson76
  • PengRobinson78
  • SoaveRedlichKwong
  • RKPR
  • PSRK Each constructor returns a configured CubicEoS with its standard alpha function, critical-property correlation, and default mixing rule.

Examples

model = PengRobinson76(Tc, Pc, omega)

Uses

    • yaeos__constants
    • yaeos__substance
