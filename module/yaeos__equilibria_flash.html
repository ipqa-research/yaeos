Flash calculations

Description

Two-phase isothermal flash calculations at specified pressure or volume. The main entry point is flash, which uses successive substitution with a Rachford-Rice inner solve. The module also provides flash_no_beta_limits, which does not force the K-factors into the region where .

Examples

result = flash(model, z, T, p_spec=P)
if (result%kind == "split") print *, result%beta, result%x, result%y
