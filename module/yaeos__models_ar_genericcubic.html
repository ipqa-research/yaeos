Generic cubic equation of state

Description

Base types and the generic implementation of a cubic equation of state. The module defines the abstract AlphaFunction and CubicMixRule types, and the CubicEoS model that combines them. Specific cubic equations are provided in yaeos__models_ar_cubic_implementations. Defines the alpha-function and mixing-rule contracts, evaluates generic cubic Helmholtz expressions, and provides model configuration methods.

Examples

model = PengRobinson76(Tc, Pc, omega)
call model%set_alpha(alpha_function)
