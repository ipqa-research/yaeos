sort

General auxiliary utilities

Small convenience procedures shared by model, solver, and phase-equilibrium code.

Description

The generic optval returns either a present optional scalar or a supplied default. sort sorts a real array in place using stdlib_sorting.

Examples

niter = optval(max_iters, 100)
call sort(values)
