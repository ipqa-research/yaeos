ddlc_Dmix

Segmented density-dependent local-composition mixing rule

Description

Implementation of the s-DDLC mixing rule, in which the attractive parameter depends on density, temperature, and composition through local-composition segment fractions. This model extends the temperature-dependent quadratic mixing rule with segment-size data and volume-dependent local compositions.

Examples

rule = sDDLC(k=k, k0=k0, tref=tref, l=l, q=q)
call model%set_mixrule(rule)
