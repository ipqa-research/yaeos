Saturation-point nonlinear systems

Residual equations, Jacobians, and point solvers for bubble, dew, and liquid-liquid states.

Description

The routines in this module encode saturation unknowns in logarithmic coordinates and enforce isofugacity, material-balance, and specification equations. They are implementation-level solvers used by the public saturation_pressure and saturation_temperature routines.

Examples

Application code should call the public saturation-point functions rather than these solver helpers.
