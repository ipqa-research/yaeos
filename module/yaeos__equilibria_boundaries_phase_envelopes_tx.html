tx_envelope_2ph

Temperature-composition phase envelopes

Continuation routines for phase boundaries in the plane.

Description

These procedures trace phase-equilibrium states while temperature and the feed interpolation parameter vary. They are useful for isobaric sections through a phase diagram and return arrays of equilibrium states.

Examples

line = tx_envelope_2ph(model, z0, alpha0, z_injection, first_point)
