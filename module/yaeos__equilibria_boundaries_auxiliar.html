Phase-boundary helper utilities

Composition interpolation and critical-region detection used by envelope solvers.

Description

Provides linear feed interpolation, its derivative, and state/index helpers that detect passage near a critical point. These are lower-level building blocks used by phase-envelope routines.

Examples

call get_z(alpha, z0, zi, z, dzda)
