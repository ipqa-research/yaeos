Equilibrium state types

Description

Derived types used to store the results of phase-equilibrium calculations. EquilibriumState holds a two-phase state and MPEquilibriumState holds a multiphase state. The values use the library’s default units: pressure in bar, temperature in kelvin, volume in litres per mole, and compositions as mole fractions.

Examples

result = flash(model, z, T, p_spec=P)
print *, result%kind, result%beta, result%x, result%y
