Hyperdual residual Helmholtz models

Base type and derivative adapter for models defined with hyperdual numbers.

Description

Extend ArModelAdiff, implement its hyperdual Ar function and the inherited volume initializer, and the adapter extracts the first and second derivatives required by the standard ArModel interface. This is the intended user entry point for operator-overloaded AD; the adapter routines are its implementation details.

Examples

All that is needed is a derived type extending ArModelAdiff, a hyperdual-valued Ar function, and the inherited volume initializer.

module newmodel
use yaeos__adiff_hyperdual_ar_api, only: ArModelAdiff
use yaeos__constants, only: pr
use hyperdual_mod, only: hyperdual
implicit none

type, extends(ArModelAdiff) :: YourNewModel
   real(pr) :: a = 1.0_pr
contains
   procedure :: Ar => arfun
   procedure :: get_v0 => v0
end type
contains
type(hyperdual) function arfun(self, n, v, t) result(arval)
   class(YourNewModel) :: self
   type(hyperdual), intent(in) :: n(:), v, t

   arval = sum(n) * t + self%a * v
end function arfun

function v0(self, n, p, t) result(vol)
   class(YourNewModel), intent(in) :: self
   real(pr), intent(in) :: n(:), p, t
   real(pr) :: vol

   vol = self%a * sum(n)
end function v0
end module newmodel
