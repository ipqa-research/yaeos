Tapenade excess-Gibbs API

Abstract interface and adapter for source-to-source differentiated GE models.

Description

GeModelTapenade adapts generated primal and derivative routines to the GeModel excess-Gibbs and activity-coefficient methods. Concrete models implement the deferred procedures declared in this module.

Examples

Extend GeModelTapenade and call the inherited GE property methods on the resulting model.

References

Tapenade documentation: https://tapenade.gitlabpages.inria.fr/
