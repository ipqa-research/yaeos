GERG2008 equation of state

Description

Multifluid equation of state for natural-gas mixtures based on the reduced Helmholtz energy. The model is constructed with gerg_2008 from the component identifiers in G2008Components. The model uses the composition-dependent reducing functions and binary departure terms of the original 21-component formulation.

Examples

model = gerg_2008([G2008Components%methane, G2008Components%nitrogen])
call model%pressure(n, V, T, P)

Ideal gas constants used on yaeos
