Cubic mixing rules

Three-component combining rules for cubic equations of state.

Description

CMR combines pure-component parameters and ternary interaction coefficients. CMRTD adds temperature dependence to its attractive interaction parameters. These types implement the CubicMixRule API.

Examples

rule = CMR(k=kijk, l=l3)
call model%set_mixrule(rule)
