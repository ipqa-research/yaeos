Excess-Gibbs models

Abstract API and thermodynamic property relations for activity models.

Description

A GeModel implementation supplies the excess Gibbs energy and its temperature/composition derivatives. The base type derives activity coefficients and excess enthalpy, entropy, and heat capacity from those derivatives. Energies are extensive and expressed in the units of , i.e. bar L with the library’s R [bar L / (mol K)].

Examples

model = NRTL(A, B, alpha)
call model%ln_activity_coefficient(n, T, ln_gamma)
