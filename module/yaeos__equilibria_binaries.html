Binary three-phase equilibrium

Utilities for liquid-liquid-vapor lines and critical endpoints in binary systems.

Description

Provides initial guesses and nonlinear residuals for binary LLV calculations, plus result storage in BinaryThreePhase. These routines exploit the fact that a binary composition has one independent composition coordinate per phase.

Examples

line = binary_llv_from_cep(model, cep)
