Hyperdual excess-Gibbs models

Base type and derivative adapter for GE models using hyperdual AD.

Description

Extend GeModelAdiff and implement the hyperdual excess-Gibbs function. The adapter extracts composition, temperature, and mixed derivatives to provide the standard GeModel activity-coefficient interface.

Examples

See the group-contribution and NRTL model implementations for examples.

References

Hyperdual arithmetic is provided by hyperdual_mod.
