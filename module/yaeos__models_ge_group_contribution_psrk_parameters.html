PSRKParameters

PSRK UNIFAC parameters

Description

Parameter set for the PSRK UNIFAC model, returned by PSRKParameters. The returned parameter type contains the PSRK subgroup definitions and main-group interaction matrices.

Examples

parameters = PSRKParameters()
call parameters%check_consistency()
