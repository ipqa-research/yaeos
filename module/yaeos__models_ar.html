Residual Helmholtz model API

Abstract model interface and property calculations based on .

Description

ArModel is the base class for equations of state and other residual Helmholtz models. Implementations provide the residual Helmholtz energy and its derivatives plus a liquid-volume initializer. The inherited methods derive pressure, fugacity coefficients, volume, and residual caloric properties. Optional derivative arguments allow callers to request only the quantities needed by their calculation.

The central pressure relation is Second derivatives are also used by stability and phase-equilibrium calculations.

Examples

class(ArModel), allocatable :: model
real(pr) :: P, dPdV
model = PengRobinson76(Tc, Pc, omega)
call model%pressure(n, V, T, P, dPdV=dPdV)

References

Michelsen, M. L., and J. M. Mollerup, Thermodynamic Models: Fundamentals & Computational Aspects, 2nd ed., 2007.

  • private subroutine abs_residual_helmholtz(self, n, v, t, Ar, ArV, ArT, ArTV, ArV2, ArT2, Arn, ArVn, ArTn, Arn2)

    abs_residual_helmholtz

    Description

    Residual Helmholtz model generic interface.

    This interface represents how an Ar model should be implemented. By our standard, a Residual Helmholtz model takes as input:

    • The mixture’s number of moles vector.
    • Volume, by default in liters.
    • Temperature, by default in Kelvin.

    All the output arguments are optional. While this keeps a long signature for the implementation, this is done this way to take advantage of any inner optimizations to calculate derivatives inside the procedure.

    Once the model is implemented, the signature can be short like model%residual_helmholtz(n, v, t, ArT2=dArdT2)
