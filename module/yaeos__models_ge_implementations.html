Excess Gibbs model constructors

Description

Convenience module that re-exports the excess Gibbs models available in yaeos: NRTL, NRTLHV, UNIQUAC, UNIFAC, and the Dortmund and PSRK variants. This is a convenience re-export module; each concrete model’s constructor and parameter requirements are documented in its implementation module.

Examples

use yaeos__models_ge_implementations, only: NRTL, setup_unifac, Groups
