Substances

Component properties

Derived type for pure-component data shared by thermodynamic models.

Description

Substances stores component names and critical properties in the order used by a model’s composition vectors. Optional allocatable arrays may be left unallocated when a model does not require those properties.

Examples

type(Substances) :: components
components = Substances(tc=Tc, pc=Pc, w=omega)
