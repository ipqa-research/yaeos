Cubic alpha functions

Component alpha-function implementations used by cubic equations of state.

Description

The module provides Soave, RKPR, and Mathias-Copeman temperature corrections. Each type evaluates and its first two derivatives with respect to reduced temperature, as required by CubicEoS.

Examples

type(AlphaSoave) :: alpha
alpha%k = k_values
call model%set_alpha(alpha)
