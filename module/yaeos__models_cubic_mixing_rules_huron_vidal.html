Huron-Vidal cubic mixing rules

Cubic-EOS mixing rules that couple an excess-Gibbs model to the attractive mixture parameter.

Description

This module implements Huron-Vidal, Michelsen-Huron-Vidal (MHV), and an NRTL-HV variant. These rules use an excess-Gibbs model to represent non-ideal liquid interactions while retaining the cubic equation of state for volumetric behavior.

Examples

ge = NRTL(A, B, alpha)
mixrule = MHV(ge=ge, b=b, q=-0.593_pr)
call model%set_mixrule(mixrule)

References

  • Huron, M.-J., and J. Vidal, Fluid Phase Equilibria 3 (1979) 255-271.
  • Michelsen, M. L., Fluid Phase Equilibria 60 (1990) 213-219.
