Multiphase PT envelopes

Trace pressure-temperature boundaries for systems with multiple phases.

Description

Continues generalized multiphase equilibrium states and stores the resulting states, phase kinds, and boundary metadata in the module’s envelope result type.

Examples

env = pt_envelope(model, z, np, kinds_x, kind_w, x_l0, w0, betas0, &
                  P0, T0, ns0, dS0, beta_w)
