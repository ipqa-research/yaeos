Predefined fluid fixtures

Ready-to-use EOS models and compositions for examples, tests, and tutorials.

Description

Each constructor returns a FixtureFluid containing the model, number of components, reference citation, and available feed/injection compositions. These are curated example data sets, not a general-purpose fluid database.

Examples

fluid = co2_h2o_isop()
call fluid%ar_model%pressure(fluid%z0, V, T, P)
