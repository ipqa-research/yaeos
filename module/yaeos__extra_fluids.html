Predefined Fluids

Collection of predefined fluids to be used as examples and in tests.

Description

This module collects a set of different fluids intended to be used for tests or in practice when training on using the library.

The fluids are stored as functions that return a derived type FixtureFluid which contains the instantiated ArModel of the fluid, and its relevant compositions z0 and zi
