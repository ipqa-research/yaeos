critical_pure_point_solver

Calculation of pure-component critical points using the yaeos equation of state and numerical derivatives.

Description

The critical point of a pure component is defined by the conditions:

This module solves the resulting nonlinear system in the variables (V, T) using a Newton-Raphson iteration. Each residual is evaluated from the equation-of-state pressure and its numerical derivatives.
