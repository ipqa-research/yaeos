Excess-Gibbs derivative kernels

Shared thermodynamic equations used by activity-coefficient model implementations.

Description

Implements the Huron-Vidal-modified NRTL excess Gibbs energy and its derivatives with respect to mole amounts and temperature, plus helpers for the temperature dependence of . These kernels are used internally by the public NRTL and NRTLHV models.

Examples

The NRTL and NRTLHV models call these kernels; application code should use their model methods.
