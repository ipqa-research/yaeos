newton_solve

Damped Newton solver

Solve small nonlinear systems using Newton steps and Armijo backtracking.

Description

newton_solve accepts a callback returning residuals and a dense Jacobian, updates the initial guess in place, and reports a convergence code. It is imported by solve_TP in this source file, although that routine currently calls newton from yaeos__math_nonlinearsolvers instead.

Examples

call newton_solve(fun, x, tol, max_iter, its, info)
