Library constants and shared settings

Precision, gas constant, unit conventions, volume-root identifiers, and shared runtime settings used throughout yaeos.

Description

pr selects the library real kind and R defines the default unit system (bar, litre, kelvin, mole). root_kinds names the stable, liquid, and vapor roots used by EOS volume calculations.

Examples

use yaeos, only: pr, R, root_kinds
real(pr) :: temperature = 300.0_pr
print *, R, root_kinds%stable
