BaseModel

Base thermodynamic model

Shared base type for all thermodynamic model families.

Description

BaseModel stores component properties through its components field. Residual Helmholtz models and excess-Gibbs models extend this base type and add their respective calculation interfaces.

Examples

class(BaseModel), allocatable :: model
model = PengRobinson76(Tc, Pc, omega)
