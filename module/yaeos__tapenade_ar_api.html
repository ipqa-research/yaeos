residual_helmholtz

Tapenade residual Helmholtz API

Abstract interface and adapter for source-to-source differentiated EOS models.

Description

ArModelTapenade requires primal, forward, reverse, mixed, and second directional derivative routines. Its implementation of residual_helmholtz dispatches to those routines to populate requested derivative outputs.

Examples

See PCSAFT in src/models/residual_helmholtz/saft/pc_saft.f90 for a production implementation and tools/tapenade_diff/ for the generator.

References

Tapenade documentation: https://tapenade.gitlabpages.inria.fr/
