GERG2008 parameters

Description

Pure-fluid and binary parameters of the GERG2008 equation of state, together with get_original_parameters, which loads them for a list of component identifiers. The loader returns pure-fluid coefficient arrays, pairwise departure parameters, and component critical constants in the requested ordering.

Examples

call get_original_parameters(ids, pures, binaries, components)

Uses

    • yaeos__constants
    • yaeos__models_base
