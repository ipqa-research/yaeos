Linear algebra helpers

Dense linear solves, eigenproblems, and cubic-polynomial root utilities.

Description

The module wraps LAPACK for linear systems and symmetric eigenproblems, and provides cubic-root solvers used by EOS implementations. solve_system solves ; eigen computes eigenpairs of a real symmetric matrix.

Examples

x = solve_system(A, b)
call eigen(A, values, vectors)

public function solve_system(a, b) result(x)

Solve the dense linear system with LAPACK dgesv. The routine expects a square nonsingular matrix; LAPACK’s status is currently not returned to the caller.
