Mathematical methods for yaeos

Description

This module provides all the relevant mathematical functions used in this library. Most important ones are:

  • newton: Newton solving method
  • solve_system: Solving linear system Ax = b
  • continuation: Continuation method for line tracing

Examples

Squared error calculation

 use yaeos__constants, only: pr
 use yaeos__math, only: sq_error
 print *, sq_error(2.5_pr, 3.0_pr)

 use yaeos__constants, only: pr
 use yaeos__math, only: sq_error
 real(pr) :: x(2) = [2.5_pr, 5.0_pr], y(2) = [3.0_pr, 4.5_pr]
 ! It also works with arrays
 print *, sq_error(x, y)

  • public subroutine newton_1d(f, x, tol, max_iters, failed)

    newton_1d

    Description

    Find a root of a scalar function by damped Newton iteration. Each step is halved until its magnitude is at most half the current iterate’s magnitude. This is a step-size safeguard, not a residual line search.

    Arguments

    Type IntentOptional Attributes Name
    procedure(f_1d) :: f

    Function and derivative callback.
    real(kind=pr), intent(inout) :: x

    Initial guess, replaced by the root estimate.
    real(kind=pr), intent(in) :: tol

    Absolute tolerance for residual and step size.
    integer, intent(in) :: max_iters

    Maximum Newton iterations.
    logical, intent(out) :: failed

    True when the iteration limit is exhausted.
