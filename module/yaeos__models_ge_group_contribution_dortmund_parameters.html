DortmundParameters

Dortmund UNIFAC parameters

Description

Parameter set for the modified UNIFAC (Dortmund) model, returned by DortmundParameters. The returned parameter type contains group identifiers, subgroup sizes, and the Dortmund main-group interaction matrices.

Examples

parameters = DortmundParameters()
call parameters%check_consistency()
